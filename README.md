# mgh-dbm25-group04-ski-resorts

Analysis of a dataset on 376 European ski resorts (as of February 2022). Includes:
1. Relationship between a ski resort’s size and daily price (Does the price rise more slowly than the length of the slopes?)
2. Differences in daily rates between Austria, France, Switzerland, and Italy within the same size category
3. Which factors explain the daily rate (slope length, elevation, amenities, country)
4. Identification of ski resort types using cluster analysis and search for notably inexpensive or expensive resorts
